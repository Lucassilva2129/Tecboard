# Tecboard

Projeto desenvolvido durante meus estudos de desenvolvimento web, com foco na prática de **HTML e CSS**.

## 🖥️ Sobre o projeto

O Tecboard é uma página web simples criada para praticar estruturação de páginas e estilização utilizando HTML e CSS.

O projeto possui layout responsivo, adaptando-se a diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- GitHub Pages

## 📚 Conceitos praticados

- Estruturação de páginas com HTML
- Estilização com CSS
- `@font-face` para utilização de fontes personalizadas
- Media Queries
- Responsividade para desktop, tablet e celular
- Pseudo-classe `:hover`
- Organização de arquivos e pastas
- Publicação de projeto com GitHub Pages

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web. A proposta foi colocar em prática os conhecimentos adquiridos em HTML e CSS e começar a construir meu portfólio de projetos.
